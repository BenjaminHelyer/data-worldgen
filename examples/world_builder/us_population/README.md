# Synthetic US working population

Generate a population and explore the proportion in each profession on a 50-state map:

```bash
pip install -e .
python3 examples/world_builder/us_population/generate.py --count 20000 --seed 42
streamlit run examples/world_builder/us_population/dashboard.py
```

The generator writes `population.parquet` alongside the example, regardless of your current directory. To choose another location, pass `--out /path/to/population.parquet` and launch the dashboard with `WORLDGEN_US_POPULATION=/path/to/population.parquet streamlit run examples/world_builder/us_population/dashboard.py`.

Choose a profession to color the map by its percentage of the **sample in each state**. Hover for counts, then choose a state below the map to view its profession distribution and 20 example characters. Alaska and Hawaii appear as insets. States with no sampled characters have no percentage. Smaller states have smaller samples and therefore noisier percentages; increase `--count` to improve coverage.

This example models **synthetic adult workers**, not the entire population. The state weights are approximate population-sized weights, not calibrated state workforce counts. The profession categories, base probabilities, state-specific multipliers and age distribution are illustrative inventions, not official statistics; the results should not be used as estimates of real employment. The map excludes DC and territories. Names are generated by the existing fictional name generator and may not resemble typical US names.

`config.json` uses the existing population configuration and sampler: `state` influences `profession` through factor multipliers. Each multiplier changes a relative weight, after which the sampler normalizes all professions for that state. The config also uses the existing truncated-normal age distribution. No core changes are needed. `states.json` supplies FIPS codes for joining map geometry, along with the approximate weights represented in the config. The seed controls sampled fields and name randomness, but generated character IDs include time/randomness and are not reproducible byte-for-byte.

The map geometry comes from the public [us-atlas](https://github.com/topojson/us-atlas) TopoJSON via jsDelivr, fetched by the browser when the dashboard renders. An internet connection to that CDN is required for the map; the state tables and character samples still work without it.
